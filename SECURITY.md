# Security and safety reporting

Clunk contains no accounts, secrets, payments, or application-side model calls. Its primary risk is unsafe or misleading repair behavior.

Please open a GitHub issue for:

- a path that exposes a forbidden repair instruction;
- an agent or manual call that bypasses the current safety check;
- a real-world diagnosis or compatibility claim;
- a WebMCP schema that accepts unintended input;
- a cross-site scripting, dependency, or deployment concern.

Do not test Clunk against a real broken appliance. The Clunk WM-01 and all parts and outcomes are fictional demonstration data.
