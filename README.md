# Clunk

**Tell it what’s broken. It shows you what to check and finds the exact part.**

Clunk is an open-source WebMCP hackathon project about a person and a browser agent diagnosing one fictional washing machine together. The finished experience will use deterministic client-side state, original appliance data and diagrams, visible WebMCP activity, and a manual judge mode.

> Clunk WM-01 and every diagnosis, part, compatibility result, and cost or effort band in this repository are fictional demonstration data. Do not use Clunk to diagnose or repair a real appliance.

## Status

The Lovable project and GitHub source-of-truth workflow were created on August 26, 2026. The portable static foundation and hackathon build documents are now in place; the repair bench is under active development.

## Local development

Requirements: Node.js 22 or newer.

1. Install dependencies: npm install
2. Start the app: npm run dev
3. Create a production build: npm run build

No account, environment variable, database, API key, or model provider is required.

## Current stack

- React
- TypeScript
- Tailwind CSS
- Vitest and Playwright
