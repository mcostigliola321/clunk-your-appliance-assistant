# Clunk

A fictional appliance repair assistant.

This first commit is a portable static Vite + React + TypeScript foundation that Lovable can host. It contains no database, authentication, server functions, analytics, payments, or external APIs.

The detailed repair bench, WebMCP tools, state engine, tests, and final styling will be added after GitHub is connected.

## Development

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
```

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- TanStack Start
